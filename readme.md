# 8 Block Puzzle 

## About

You can move the blank space by typing the number you want to switch it with, but there are some rules:
1. The number should be directly adjacent to the blank space.
2. The number can only move vertically and horizontally and not diagonally.


## Goal

The goal of this game is to make the pattern look like the image below.

## New Update 

Added a custom made algorithm that uses an uninformed search technique to solve the puzzle
For this puzzle i used Breadth first search where we first expand the root node and then we 
expand its child nodes and so on.
